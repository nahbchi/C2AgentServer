# **C2AgentServer**  
**Python-based Command and Control (C2) Server for Cybersecurity Research**

---

## **Overview**  
**C2AgentServer** is a Python-based tool designed to simulate **Command and Control (C2)** communication between a server and compromised clients. This framework is intended for **cybersecurity professionals**, **penetration testers**, and **researchers** to study C2 behavior and enhance their understanding of botnet management, malware command execution, and data exfiltration tactics.

---

## **What is a C2 Server?**  
A **Command and Control (C2) server** is used by attackers to manage a network of compromised machines, issuing commands and receiving data. Analyzing C2 servers is essential for:

- **Identifying and disrupting** botnet operations.
- **Simulating attacks** for penetration testing.
- Understanding **malware behavior** and **data exfiltration techniques**.

---

## **Features**  
- **Encrypted Communication**: Simulate real-world C2 protocols with **SSL/TLS** encryption.
- **Client Management**: Add/remove simulated compromised clients.
- **Command Execution**: Issue commands to collect system data or perform actions.
- **Heartbeat System**: Clients periodically report to the server to maintain control.
- **Data Logging**: Track all commands and client responses for analysis.
